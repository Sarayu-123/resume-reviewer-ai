# Resume Reviewer AI

An AI-powered resume analysis project developed through two iterations.

## Version 1 — Streamlit

Python + Streamlit + Ollama

The initial prototype provides:

- PDF/DOCX resume extraction
- Resume section detection
- Resume scoring
- Role-based skill matching
- Matched and missing skills
- AI-powered bullet suggestions

[View Version 1](./version-1-streamlit)

## Version 2 — Next.js + FastAPI

Next.js + React + TypeScript + FastAPI + Ollama

The second version improves the original prototype with:

- Modern web frontend
- Next.js and React
- TypeScript
- Dedicated FastAPI backend
- Frontend/backend separation
- Improved UI
- Structured backend agents and utilities
- Local AI integration through Ollama

[View Version 2](./version-2-nextjs-fastapi)

## Evolution

| Feature | Version 1 | Version 2 |
|---|---|---|
| Frontend | Streamlit | Next.js + React |
| Backend | Python/Streamlit | FastAPI |
| Languages | Python | TypeScript + Python |
| AI | Ollama | Ollama |
| Architecture | Prototype | Frontend + Backend |
| UI | Streamlit | Custom Web UI |

## Goal

The project demonstrates the progression of a basic AI resume analysis prototype into a structured full-stack application.
